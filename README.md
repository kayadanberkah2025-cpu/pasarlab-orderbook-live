# PasarLab Market Scanner

Open the [Hype Scanner](./hype-scanner.html) or the [live order book](./orderbook.html).

The scanner ranks active Bybit USDT perpetual markets using public ticker data directly in the browser. BUY/SELL bias labels are informational rule-based signals, not investment advice or automated orders.

## Order book

The order book displays public Bybit V5 linear-perpetual market data directly in the browser.
